HearBridge PS4
v1.0.0
HighlightsRequirementsInstallGood to knowUninstall

Your PS4 game sound on regular Bluetooth headphones.

HearBridge PS4 drives a small USB Bluetooth dongle (CSR8510) and streams game audio to any A2DP headset, earbuds or speaker. You control everything from a web page served by the console, on a phone, a PC or the PS4 browser.

Download v1.0.0Source on GitHub

Highlights

  • Game audio on any Bluetooth headphones, earbuds or speakers.
  • Scan, pair and connect from a web page. Up to 8 saved devices, with automatic reconnect.
  • Headphone volume and a Boost slider for quiet games.
  • Five band equalizer with presets.
  • Game profiles: each game keeps its own sound, applied when the game starts.
  • Switch game audio on or off, or skip games you do not want to stream.
  • A launcher tile that sets everything up and starts the service.

Requirements

  • A jailbroken PS4 running GoldHEN, with the BinLoader server and Plugin Loader switched on.
  • A USB Bluetooth dongle with the CSR8510 chip (USB ID 0A12:0001), plugged into the PS4.
  • Bluetooth headphones, earbuds or a speaker.

Install

  1. Install HearBridge-PS4-1.0.0.pkg with GoldHEN's package installer. A HearBridge tile appears on the home screen.
  2. In the GoldHEN settings, turn on BinLoader server and Plugin Loader.
  3. Plug the dongle into the PS4 and open the HearBridge tile. It installs the game audio plugin, starts the service and shows the page address. If it asks you to turn on Plugin Loader, do that and restart the console once.
  4. Open http://<console-ip>:8090 on a phone or PC on the same network, or press OK on the tile message and then X (Circle if your console is set that way) to open it in the PS4 browser.
  5. Press Scan for devices, put your headphones in pairing mode and tap Pair.
  6. Start a game. The sound plays on your headphones.

HearBridge keeps running after the tile closes and reconnects to your last headphones by itself. Restarting the console once after the first install is recommended, so games start smoothly.

Good to know

  • HearBridge never touches the console's built-in Bluetooth chip, so your controllers stay connected as usual.
  • Bluetooth adds a little delay, so the headphones play slightly behind the TV.
  • Only game audio is streamed, not the home screen sounds or voice chat.
  • Game audio is picked up from a game's main and background music outputs at 48 kHz (almost all games). A game that opens its audio at another rate is not streamed.
  • The launcher turns on Plugin Loader in GoldHEN's config.ini and adds the plugin to plugins.ini under [default], keeping config.ini.bak / plugins.ini.bak the first time.
  • Anyone who can open the page on your network can control it, so use a home network you trust.

Uninstall

Delete the HearBridge app from the PS4. To remove everything, also delete /data/GoldHEN/plugins/hearbridge_game_tap.prx, its line in /data/GoldHEN/plugins.ini, the folders /data/hearbridge and /data/GoldHEN/hearbridge, and the files hearbridge_skip.txt and hearbridge_tap_off in /data/GoldHEN. Restart the console to stop a running service.
